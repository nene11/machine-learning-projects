# Energy Demand Forecasting

**Level:** Advanced | **Task:** Time-series forecasting

Dataset: UCI Individual Household Electric Power Consumption.

Method: chronological split + lag features + rolling statistics + gradient boosting.

Skills: temporal validation, leakage prevention, lag engineering, MAE/RMSE and forecasting error analysis.

Run after downloading/extracting the UCI dataset and pointing `src/train.py` to the local file.
