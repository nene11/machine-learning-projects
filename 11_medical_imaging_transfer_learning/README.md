# Deep Learning Medical Imaging — Transfer Learning Blueprint

**Level:** Advanced–Expert | **Task:** Medical image classification

## Objective
Build a reproducible medical-image classification workflow using transfer learning, augmentation, class-imbalance handling and explainability.

## Proposed public dataset
Use a documented public medical-image dataset such as NIH ChestX-ray14 or a MedMNIST classification dataset. Dataset license/terms must be reviewed before redistribution.

## Workflow
Data acquisition → patient-level split where applicable → image quality audit → augmentation → pretrained CNN → fine-tuning → ROC-AUC / PR-AUC / F1 → calibration → confusion matrix → Grad-CAM → error analysis.

## Safety
This is a research portfolio project, not a clinical diagnostic system. No clinical claims are made.
