# Detailed Report — Customer Churn Prediction

## Problem
Estimate the probability that a telecom customer will churn.

## Data
Public IBM Telco Customer Churn dataset. `TotalCharges` is converted to numeric and customer ID is removed because it is an identifier rather than a predictive feature.

## Pipeline
1. Load data.
2. Clean numeric fields.
3. Separate target and features.
4. Build a preprocessing pipeline for numeric/categorical variables.
5. Split using stratification.
6. Train gradient boosting.
7. Evaluate probability quality with ROC-AUC and PR-AUC.

## Engineering controls
Preprocessing is fitted inside the pipeline to reduce leakage risk. Unknown categories are tolerated at inference time.
