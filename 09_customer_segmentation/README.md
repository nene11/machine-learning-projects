# Customer Segmentation & RFM Analytics
**Level:** Intermediate–Advanced | **Task:** Unsupervised learning

## Objective
Identify actionable customer groups using Recency, Frequency and Monetary behavior.

## Workflow
RFM construction → skew/outlier treatment → scaling → K-Means → silhouette evaluation → cluster profiling → marketing actions.

## Business output
Clusters are translated into personas such as high-value loyal, promising, at-risk and low-engagement segments.
