# Data

This project uses the UCI Individual Household Electric Power Consumption dataset as a public real-world time-series forecasting benchmark.

Source: UCI Machine Learning Repository, dataset 235.

The dataset contains 2,075,259 one-minute measurements over almost four years and includes missing measurements. Raw data is intentionally not committed to Git; the training script downloads it from the official UCI source at runtime.

Forecast target: daily global active power.
