# Customer Churn Prediction

**Level:** Intermediate–Advanced  
**Task:** Binary classification  
**Dataset:** IBM Telco Customer Churn (public dataset)

## Objective
Predict customer churn and demonstrate a business-oriented ML workflow with preprocessing, leakage control, class-imbalance awareness, probability scoring, and threshold selection.

## Methods
- Numeric imputation and scaling
- Categorical one-hot encoding
- Stratified train/test split
- Gradient-boosting classifier
- ROC-AUC and PR-AUC
- Error and threshold analysis

## Reproducibility
`python src/train.py`

Execution metrics are recorded only after a real run.
